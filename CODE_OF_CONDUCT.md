# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

## In short

Be respectful. Assume good faith. Critique code and claims, not people.

## Specific to this project

LossLedger publishes findings about other people's software. That carries an
obligation:

- **Maintainers hear it before the public does.** Always.
- **Report default-configuration behaviour as exactly that**, never as "X is
  broken", and show the tuned result beside it.
- **Praise what passed as loudly as what failed.** A report that only lists
  failures is marketing, not measurement.
- **No gloating.** Ever.

## Reporting

Report unacceptable behaviour to the repository owner. Reports are handled
confidentially.
